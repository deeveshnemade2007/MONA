# MONA – Personal E-Diary

**Your Space. Your Pace. Your Progress.**

MONA is a personal digital diary designed to bring everyday organization into one simple, private space. It helps you manage daily tasks, track expenses, save important information, organize goals, and keep track of things that matter.

## ✨ Features

- **Dashboard** – A central overview of your daily activities.
- **To-Do List** – Organize tasks and track completion.
- **Monthly Expenses** – Manage income, expenses, and monthly balance.
- **Important Points** – Save important notes and information.
- **Important Dates** – Keep track of upcoming events and deadlines.
- **Shopping List** – Manage items you plan to purchase.
- **Goal Vault** – Store and organize personal goals.
- **Brain Dump** – Capture thoughts and ideas.
- **Watchlist** – Keep track of movies and shows you want to watch.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Supabase – Database and authentication
- Vercel – Deployment

## 🔐 Privacy

MONA is designed for personal use. It uses Supabase authentication and database access policies to protect personal diary data.

## 🚀 Getting Started

1. Clone this repository.
2. Open the project folder in VS Code.
3. Configure your Supabase project credentials in `config.js`.
4. Open `index.html` using Live Server.

## 🎯 Purpose

To create one personal space where tasks, thoughts, plans, and everyday activities stay organized.
